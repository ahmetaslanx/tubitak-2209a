# TÜBİTAK 2209-A: Trigonometrik Notalar ile Kriptografik Veri Kodlama

Python kullanarak müzik dosyalarının içine gizli veri saklayan (steganografi) ve ses dalgaları üzerinden şifreli iletişim sağlayan bir araştırma projesidir.

---

## Proje Ne Yapar?
* Metinleri ikilik koda çevirip nota frekanslarıyla eşleştirir.
* Şifreleme için dinamik bir dönüşüm matrisi kullanır.
* Şifrelenmiş veriyi %5 oranında müzik dosyalarına gizler.
* Hızlı Fourier Dönüşümü (FFT) kullanarak müzik içindeki gizli veriyi geri çözer.

---

## Kullanılan Teknolojiler
* Python
* NumPy
* SciPy
* Matplotlib
